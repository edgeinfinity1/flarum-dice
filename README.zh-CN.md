# Flarum 骰子

本地开发版 **0.1.0-beta.1**，适配 Flarum 2.0.2 / PHP 8.3；尚未公开发布。英文说明见 README.md。

在发言中输入 [1, 20]、[5, 10]、[-10, 10] 等闭区间整数占位符。帖子与发送预览显示“结果 → 占位符原文 → 图标”，输入框保留文本。新帖由服务端在写入时生成结果，预览和草稿只显示问号；组件不能点击重掷。端点相等的单结果区间允许使用，其结果本来就是确定的。

## 本版编辑与数据规则

- 已掷骰的帖子可以修改其它文字或占位符空白；骰子数量、范围和顺序必须保持不变，不能通过编辑重掷、追加或删除骰子。
- 旧帖不批量改写、不补掷；原本没有结果的帖子在编辑时加入占位符，也不会获得结果。
- 软删除／恢复保留结果；永久删除帖子或讨论时，结果随帖子行一起删除。
- 禁用、Composer 移除或后台卸载均保留 posts.edge_dice 字段，重装后可恢复。停用期间改动了骰子序列，结果保持休眠；恢复完整原序列才会重新显示，绝不重新随机分配。
- 停用并重编译资源后，正文退回原始占位符，不依赖本插件前端。彻底销毁结果属于单独的数据库操作，步骤见 docs/LIFECYCLE.md。
- 发帖者仍可能删除整帖后重新发帖；相同范围的多个骰子也不能证明其周围叙事未变。本插件不声称提供独立于管理员的可验证公平性。

## 语法与外观

只接受英文中括号、英文逗号和整数，可有空格、制表符及正负号。端点范围为 ±1,000,000,000。每条新帖默认最多 50 个骰子，后台可设为 1–100。代码、引用和链接标签不生成骰子；要展示原样示例，使用行内代码或转义左中括号。Markdown 引用式链接有语法歧义时请用代码明确表达。

后台“扩展 → Dice”可配置：大成功／大失败开关、最少面数、两端比例、高点或低点为成功；跨零区间的正负零；重复数字、递增／递减连号的最少位数；特殊数字列表和显示优先级。默认 20 面起触发临界效果，两端各 5%。每项效果可分别设置浅色／深色的文字、背景及图标颜色，颜色只支持十六进制或留空。多个效果同时命中时按优先级取色，标准 Flarum tooltip 展示全部命中效果。

仅精确 [1, N] 且 N 为 4、6、8、10、12、20、100 时使用提供的七张 PNG 遮罩，其余使用通用骰子图标。图标随配色变化。设置只影响显示，永不改变已保存结果。
