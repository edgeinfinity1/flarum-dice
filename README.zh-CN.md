# Flarum 骰子

本地开发版 **0.1.0-beta.1**（首轮审阅修订），适配 Flarum 2.0.2 / PHP 8.3；尚未公开发布。英文说明见 README.md。

在发言中输入 [1, 20]、[5, 10]、[-10, 10] 等闭区间整数占位符。帖子与发送预览显示“结果 → 占位符原文 → 图标”，输入框保留文本。服务端在保存新帖或需要新结果的编辑时出点；预览和草稿不出点，新骰子显示问号。组件不能点击重掷。端点相等的单结果区间允许使用，其结果本来就是确定的。

## 编辑与数据规则

- 默认允许修改、增加和删除骰子，仍受论坛原有编辑权限约束。相同范围按出现顺序复用已有结果，即使移动位置也不重掷；新范围或无法复用的骰子只在保存时出点。失去引用的结果从账本清除。仅修改叙述或占位符空白不会重掷。
- 骰子序列变化后，所有保留骰子标记“已编辑”，包括复用的结果：删去不利结果也可能造成选择偏差。默认使用问号图标，后台可关闭标记或更换图标。这是提示可能性，不是认定作弊。删除所有骰子后只保留很小的编辑标记，不保留被删结果；再次添加仍有提示。
- 后台可关闭“允许编辑骰子”。关闭后，含已掷骰的帖子须保持数量、范围和顺序，其它文字／空白仍可编辑。整帖删除继续遵守论坛权限。
- 首次安装不会批量改写或补掷旧帖。开启编辑时，用户主动编辑旧帖并保存新／变化的占位符，可以获得结果，同时标记已编辑。
- 软删除／恢复保留结果；永久删除帖子或讨论时，结果随帖子行一起删除。
- 禁用、Composer 移除或后台卸载均保留 posts.edge_dice 字段；重装可恢复匹配的旧结果。停用期间若改动骰子序列，浏览时不会错套旧结果或自动补掷。恢复原序列可恢复显示；开启编辑后主动保存变化序列，按上述复用／重掷规则处理。
- 停用并重编译资源后，正文退回原始占位符，不依赖本插件前端。彻底销毁结果属于单独数据库操作，步骤见 docs/LIFECYCLE.md。
- 用户仍可能删除整帖后重发；相同范围骰子的周围叙述也可以改变。本插件不声称提供独立于管理员的可验证公平性。

## 语法与外观

只接受英文中括号、英文逗号和整数，可有空格、制表符及正负号。端点范围为 ±1,000,000,000。默认每帖最多 50 个骰子，后台可设为 1–100。代码、引用和链接标签不生成骰子；要展示原样示例，使用行内代码或转义左中括号。Markdown 引用式链接有歧义时请用代码明确表达。

大成功／大失败默认从 20 面起触发，取两端各 1 个结果，可配置固定个数、最少面数及高／低点成功。个数最多取面数一半，避免重叠。旧百分比配置自动按个数 1 解读，其它规则和配色保留。还可配置跨零区间正负零、重复数字、递增／递减连号最少位数、特殊数字列表及效果优先级。

每项效果可分别设置浅色／深色的文字、背景及图标颜色，只接受十六进制或留空。多个效果同时命中时，按最高优先级决定配色和提示词。效果名称可自定义，留空用翻译。标准 tooltip 示例：“1至100（100面）；结果100—大成功”。

精确 [1, N] 且 N 为 4、6、8、10、12、20、100 时默认使用七张 PNG 遮罩，可逐项关闭，也可逐项改为 Font Awesome 或普通图片 URL（站点根路径或 HTTP(S)）。普通图片保留原色；遮罩和字体图标随配色变化。图片加载失败回退通用图标，没有新增上传接口。d8 使用用户修订的 die_8_2.png。

普通图标默认 far fa-dice，编辑标记默认 far fa-question，均可配置。本站前后台已通过浏览器验证 Font Awesome 7 Pro 常规字重可用。当实际字体为 Font Awesome Free 时，这两个默认图标回退同字体的实心字重；也可明确配置 fas fa-dice / fas fa-question。其它自定义图标需要站点提供对应字体。
